IBM Plex, self-hosted

If this page renders in Plex, your /fonts/ directory is wired up correctly and no external CDN is in play. View source for the bare-minimum HTML.

Other families

Embed it on your own site

<link rel="stylesheet"
      href="/assets/ibm-plex-fonts/web/ibm-plex.css">

<style>
  body { font-family: "IBM Plex Sans", system-ui, sans-serif; }
  code { font-family: "IBM Plex Mono", monospace; }
</style>

For Arabic, Hebrew, Devanagari, or Thai, link the per-family CSS in the matching fonts/<family>/css/ directory — they ship pre-built by IBM with proper unicode-range subsetting. CJK families aren't bundled in this repo; see FAMILIES.md if you ever need them.
